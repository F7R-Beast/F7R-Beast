### Toys4Us

**PHP / Twig / Slim / MySQL / JavaScript**

A full e-commerce platform developed for a toy store.

- Developed user registration, authentication, profiles, and account management.
- Implemented product browsing, filtering, shopping cart, checkout, and order history.
- Integrated Stripe for online payments.
- Implemented two-factor authentication.
- Added bilingual English/French support.
- Developed administrative tools for managing products, users, and orders.
- Built a Build-a-Plush system allowing users to customize their own plush toy.
- Implemented REST APIs and AJAX-based functionality.
- Applied input validation and security practices including XSS prevention and prepared SQL queries.

- Added push notifications.
- Integrated text-to-speech functionality.
